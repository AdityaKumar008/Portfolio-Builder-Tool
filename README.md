# Portfolio Builder Tool

## Description

Portfolio Builder Tool is a web-based application that allows users to create a personal portfolio by filling out a form and selecting from multiple templates. The portfolio is generated dynamically using user-provided data.

## Live Demo

**Link:** https://adityakumar008.github.io/Portfolio-Builder-Tool/

## Features

* Template selection
* Form-based data input
* Dynamic portfolio generation
* Download option available

## Tech Stack

* HTML
* CSS
* JavaScript
* localStorage

## How to Run

1. Clone the repository
2. Open `index.html` in any modern web browser

## Project Structure

* `index.html` – Landing page
* `form.html` – User input form
* `templates.html` – Template selection
* `template1.html` to `template4.html` – Portfolio templates
* `style.css` – Common styles
* `script.js` – Logic and data handling
